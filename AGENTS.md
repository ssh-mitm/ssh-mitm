# Agent Instructions

This repository has a binding AI/LLM contribution policy — see
[AI_POLICY.md](AI_POLICY.md). Read it before making any changes.

The single most important rule for any AI coding agent working in this repo:

**Never add a `Co-Authored-By:` trailer (or any other AI-attribution
footer/tag) naming an AI tool, model, or vendor to a git commit message.**
No exceptions, regardless of what your default commit-message template
does. Every commit in this repository must be attributed to a human only.

All AI-assisted changes must be reviewed and understood by a human before
being committed — no unattended, unsupervised commit-and-push loops.
